# HTMLニトリ（仮） GitHub Pages版

3色配色とレイアウトを別々に選び、AIに貼るための合成プロンプトを作る静的Webサイトです。

この版は **GitHub Pagesだけで使う版** です。Electron、Node.js、`起動.bat` は使いません。

> 注意: 「HTMLニトリ」は仮称です。公開サービスにする場合は、実在ブランドと誤認されない名前へ変更してください。

---

## GitHub Pagesでの使い方

1. このフォルダーの中身をGitHubリポジトリのルートへアップロードする。
2. GitHubの `Settings` → `Pages` を開く。
3. `Deploy from a branch` を選ぶ。
4. `main` / `/root` を選んで保存する。
5. 表示されたGitHub Pages URLを開く。

詳しい手順は `docs/GitHub_Pages_公開手順.md` を見てください。

## この版で崩してはいけない仕様

- GitHub Pagesで開ける静的構成を維持する。
- `index.html` をリポジトリ直下に置く。
- Electron、Node.js、起動.bat必須の構成に戻さない。
- 外部APIやAPIキーを必須にしない。
- 配色データは `data/templates.json`、レイアウトデータは `data/layouts.json` に分けて管理する。
- ローカル直開き対応を残す場合は、`js/templates-data.js` と `js/layouts-data.js` も同期する。
- 実在ブランドや特定サイトの完全コピーではなく、雰囲気と構造だけを参考にしたプロンプトにする。

## JSONデータ構造

テンプレートは `data/templates.json` で管理します。

```json
{
  "id": "color-ratio-001",
  "number": 1,
  "title": "アイボリーベース・トープアクセント・テラコッタ少量",
  "category": "ベージュ系",
  "icon": "🎨",
  "mood": ["上品", "ナチュラル", "温かい"],
  "colors": ["#f8f1e7", "#8b6f47", "#c4472d"],
  "target": "サイト内容は固定しない。配色比率だけを指定する。",
  "description": "ベース色を画面の大部分に使い、主アクセントと少量アクセントを控えめに使う配色。",
  "features": ["ベース色を画面の70〜80%に使う", "主アクセントは15〜25%", "少量アクセントは5%以下"],
  "sections": ["ベース色の役割", "主アクセントの役割", "少量アクセントの役割"],
  "prompt": "AIに貼る配色メモ本文"
}

補足: 色テンプレはサイト題材ではありません。`colors` の3色を、ベース色・主アクセント・少量アクセントとして `js/main.js` が表示とプロンプトに使います。
```

## テンプレを追加する方法

1. `data/templates.json` に1件追加する。
2. ローカル直開き対応も維持する場合は、同じ内容を `js/templates-data.js` にも反映する。
3. `id` は重複させない。
4. `colors` は3色入れる。
5. `prompt` はAIにそのまま貼れる文章にする。

## 2026-06-12 追記: 色テンプレを「サイト内容」ではなく「配色指定」として扱う修正

ユーザー要望により、合成プロンプト内で色テンプレのタイトルや元用途を、作成するサイトの題材として扱わないように修正しました。

### 修正理由

色テンプレは、あくまで「色・雰囲気」を選ぶためのものです。  
例えば「サブスク紹介LP」という色テンプレを選んでも、サブスク紹介サイトを作りたいとは限りません。

### 修正内容

- `result.html` に「作りたいサイトの内容（任意）」入力欄を追加。
- 入力欄に書いた内容を、合成プロンプトの最優先内容として扱うように変更。
- 入力欄が空の場合でも、色テンプレ名や元の想定用途から勝手にサイト内容を決めない指示を出すように変更。
- `js/main.js` の `buildCombinedPrompt()` を修正。
- `buildStylePrompt()` を追加し、色単体のプロンプトも「色・雰囲気だけ」のメモになるように変更。
- `data/templates.json` と `js/templates-data.js` 内の `prompt` も、具体的サイト作成指示ではなく色指定メモへ更新。

### 追加で崩してはいけない仕様

- 色テンプレの `title` / `category` / `target` は、サイト内容として固定しない。
- 色テンプレは配色、余白感、雰囲気、ボタンやカードの見た目だけに使う。
- 作るサイトの題材は `result.html` の「作りたいサイトの内容」欄、またはユーザーがAIへ別途書く内容を優先する。
- レイアウトテンプレは骨組みの指定として使い、文章や題材はユーザーの目的に合わせて置き換える。

### 追加で崩してはいけない仕様

- 比較リストは最大3件までにする。
- 比較リストは `localStorage` の `htmlNitoriCompareStyles` に保存する。
- 出力条件は `localStorage` の `htmlNitoriPromptOptions` に保存する。
- 最終プレビューは実際のサイト内容を決めるものではなく、配色比率と画面構造の確認用とする。
- `result.html` の任意入力欄が、最終的なサイト内容として最優先される仕様は維持する。
- 検索・タグ領域を常時固定表示へ戻さない。
