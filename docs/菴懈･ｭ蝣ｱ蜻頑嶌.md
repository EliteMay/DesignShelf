- 飲食店

- EC・ショップ

## 重要な判断

- 外部APIは使っていません。
- AIはサイト内に内蔵していません。
- AIに貼るためのプロンプトをコピーする方式にしました。
- `data/templates.json` を主データとして扱います。
- ブラウザで直接 `index.html` を開いたときにも動くように、同じデータを `js/templates-data.js` にも入れています。

- `HTMLニトリ` は仮称です。公開する場合は、商標や誤認を避けるため別名に変更するのが安全です。
- 各テンプレは実在ブランドを完全コピーするものではなく、一般的なデザイン方向性をプロンプト化したものです。
- テンプレを追加するときは `id` の重複に注意してください。

## 検証内容

ユーザーの「このサイトを40点としたとき、100点にするには何が必要か。それを追加してほしい」という要望に対応するため、配色・レイアウト・プロンプト生成の流れをさらに実用向けに改善した。

### 判断した改善方針

100点に近づけるために必要なのは、テンプレ数をさらに増やすことではなく、次の4点だと判断した。

1. 100件の配色から候補を比べやすくすること。
2. 最終結果ページで、選んだ配色と構造の組み合わせを確認できること。
3. AIに貼る前に、出力形式や細かい条件を選べること。
4. 完成プロンプトをコピーだけでなく保存できること。

### 変更内容

- `index.html` に配色比較エリアを追加。
- `js/main.js` に比較リスト管理機能を追加。
  - 最大3件まで追加可能。
  - `localStorage` の `htmlNitoriCompareStyles` に保存。
  - 比較リストから「この色にする」「詳細」「外す」ができる。
- 配色カードに「比較」ボタンを追加。
- `result.html` に最終プレビューエリアを追加。
- `result.html` に出力条件パネルを追加。
  - ファイル構成選択。
  - CSS変数利用の有無。
  - 画像なし対応の有無。
  - 使い方メモ追加の有無。
- `js/main.js` の `buildCombinedPrompt()` を修正し、出力条件を完成プロンプトへ反映するようにした。
- 完成プロンプトを `.txt` として保存する `downloadPrompt()` を追加。
- カラーコードコピー時に、コピーしたことが視覚的に分かる `.copied` 表示を追加。
- `css/style.css` に比較カード、出力条件パネル、最終プレビュー、コピー演出のスタイルを追加。

### 変更ファイル

```txt
index.html
result.html
js/main.js
css/style.css
README.md
docs/作業報告書.md
```

### 検証

- `data/templates.json` のJSON構文を確認。
- `data/layouts.json` のJSON構文を確認。
- `js/main.js` を `node --check` で構文確認。
- 配色100件、レイアウト64件は維持。
- 外部API、APIキー、有料サービス依存なし。
- 検索・タグ領域の固定表示は再追加していない。

### 完了条件

- 配色を最大3件まで比較できる。
- 配色とレイアウトを選ぶと、結果ページで組み合わせの見本が見える。
- 完成プロンプトの出力条件を選べる。
- 完成プロンプトをコピー・txt保存できる。
- READMEと作業報告書に変更内容を追記済み。
